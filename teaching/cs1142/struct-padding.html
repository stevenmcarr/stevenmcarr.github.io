Alignment rules (x86-64)

char 1 byte, any offset int 4 bytes, offset % 4 == 0 long 8 bytes, offset % 8 == 0 padding (unused, garbage)

The whole struct is aligned like its strictest member, so its size is rounded up to a multiple of that alignment.
